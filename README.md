# 🎄 ツリー・デコレーター

Three.js + WebXR で作った、VR / AR / 通常ブラウザで遊べる単一HTMLファイルのミニゲーム。
大きなクリスマスツリーに飾りを投げて飾る「デコレーター」モードと、60秒間で的を撃つ「シューティング」モードを収録。

## 動作環境

| モード | 必要環境 |
|---|---|
| VR | Meta Quest ブラウザ(immersive-vr対応) |
| AR | Android + Chrome(ARCore対応機種)、または Meta Quest ブラウザ(パススルー) |
| ブラウザ | 通常のPC/スマホブラウザ(マウス or タッチのみ) |

いずれも `https://` で配信されたページで開く必要があります。ローカルファイル(`content://`や`file://`)から直接開くと、カメラ・空間トラッキングの許可が下りずAR/VRセッションが開始できません。

## 遊び方

1. トップ画面で「🎄 デコレーター」か「🎯 シューティング」を選ぶ
2. VR / AR / ブラウザのいずれかのボタンで開始
3. **AR の場合**: 床にリングが表示されるので、下のスライダーでリングの大きさ(=ツリーの大きさ)を調整し、「ここに固定する」を押すと配置完了
4. 画面タップ/コントローラーのトリガーを押すと飾りが1つ手元に出現
5. 下に出る色見本から色を選ぶ
6. もう一度つかんでドラッグし、離した瞬間の動きの速さと方向で投げる
   - デコレーター: ツリーに当たると飾りが固定されてスコア加算
   - シューティング: 浮遊する的に当てると破壊してスコア加算、60秒でラウンド終了

外れて地面に落ちて止まった飾りは、少ししてから自動的に消えます(次のタップでまた新しく出せます)。

## ファイル構成

- `tree_game.html` — ゲーム本体(単一ファイル、外部依存はThree.jsのみ)

## 技術メモ

- **描画**: three.js (`three@0.160.0`, jsDelivrのESMビルドをimportmapで読み込み)
- **VR**: `navigator.xr.requestSession('immersive-vr')`。コントローラーは `renderer.xr.getController()` の `selectstart` / `selectend` で掴む/投げるを実装
- **AR**: `navigator.xr.requestSession('immersive-ar')` + `hit-test` フィーチャーで床面を検出し、リング(reticle)を表示。`dom-overlay` フィーチャーでスライダーやボタンなどの通常HTML UIをAR映像の上に重ねている
- **ツリーの固定**: hit-testで得た床の姿勢にツリーグループを移動し、スライダーの値でuniformスケールをかけて配置
- **投げの物理**: 掴んでいる間の位置履歴(直近数フレーム)から速度ベクトルを算出し、離した瞬間にその速度で放つ簡易物理(重力+床/ツリーとの当たり判定)
- **ブラウザ(非XR)モード**: レイキャストで飾りをつかみ、カメラ前方の仮想平面にドラッグ、離すと同様に投げる

## 既知の制約

- 本物のQRコード(画像)を認識してツリーを固定する機能は、標準のWebXR ARではページ側からカメラ映像そのものを読み取れない(プライバシー上の制約)ため実装していません。代わりに端末標準の床面認識(hit-test)でツリーを固定しています
- シューティングモードの的は常にワールド原点付近を基準に出現するため、AR中にツリーを大きく移動させると的とツリーの位置関係がずれることがあります
